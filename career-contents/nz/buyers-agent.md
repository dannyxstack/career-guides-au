# Buyer's Agent（Buyer's Agent）职业分析 · 新西兰

**职业代码：612114 – Buyer's Agent。**

Buyer's Agents represent home buyers in finding, evaluating, and negotiating property purchases, requiring a New Zealand real estate agent license. This occupation is not on skilled migration lists or the Green List, making immigration feasibility low, primarily relying on Accredited Employer Work Visa (AEWV) or local experience.

> 注：本职业为**非技术移民职业**，不在新西兰技术移民职业清单上，以下内容主要面向本地就业与职业了解。

## 6. 移民路径 / PR难度

**本职业为非技术移民职业。** 通常不在澳洲技术移民职业清单（MLTSSL / STSOL / CSOL）上，不能作为独立的技术移民或雇主担保提名职业。如以移民为目标，建议考虑清单上的相关职业，或通过学生、毕业生工作、家庭团聚等其他签证类别。具体以 Department of Home Affairs 最新规定为准。

| 签证类别 | 说明 |
|---|---|
| Subclass AEWV（Accredited Employer Work Visa） | 需获得认证雇主offer，且雇主需支付不低于中位数工资(约29.66纽币/小时)，但该职业不在绿色清单中，移民路径有限 |
| Subclass SMC（Skilled Migrant Category） | 职业非技术移民列表，但若薪资达到中位数两倍(约118,640纽币)且工作满24个月，可尝试申请，难度高 |
| Subclass Visitor Visa（Visitor Visa） | 不能在新西兰工作，仅可短期考察 |

## 7. 适合人群 / 不适合人群

**谁适合学Buyer's Agent？**
- 有地产交易经验或投资背景，喜欢挑战和谈判的人
- 具备较强销售技巧和社交能力，能应对市场波动
- 愿意长期在新西兰发展，能接受移民路径有限的现实

**谁不适合学Buyer's Agent？**
- 对收入不确定性敏感，希望稳定薪水的求职者
- 无法通过AEWV或SMC获得居留权，且不愿投入时间成本的人

## 9. FAQ 常见问题

**问：Is the income of a buyer's agent stable? What does it include?**
答：Income is unstable, typically base salary plus commission. Entry-level agents earn around NZ$45,000-$65,000 per year, while senior agents can earn over NZ$100,000, but it is highly affected by the market.

**问：How to immigrate to New Zealand as a buyer's agent?**
答：This occupation is not on the Green List or skilled migration list. The main pathway is to obtain an AEWV work visa, then after working for some time, if salary reaches twice the median wage (approx. NZ$118,640), one may attempt SMC, but it is difficult. It is advisable to immigrate through other occupations or a partner.

**问：What license does a buyer's agent need? How to obtain it?**
答：Must hold a New Zealand real estate agent license, which requires completing a REINZ-recognized course (e.g., New Zealand Certificate in Real Estate, about 12 weeks), and passing REA exams and background checks.
