# Security Guards（Security Guards）职业分析 · 美国

**职业代码：33-9032 – Security Guards。**

Security guards patrol and monitor premises to prevent theft, violence, or rule violations, and may operate X-ray and metal detector equipment.

> 注：本职业为**非技术移民职业**，不在美国技术移民职业清单上，以下内容主要面向本地就业与职业了解。

## 6. 移民路径 / PR难度

**本职业为非技术移民职业。** 通常不在澳洲技术移民职业清单（MLTSSL / STSOL / CSOL）上，不能作为独立的技术移民或雇主担保提名职业。如以移民为目标，建议考虑清单上的相关职业，或通过学生、毕业生工作、家庭团聚等其他签证类别。具体以 Department of Home Affairs 最新规定为准。

| 签证类别 | 说明 |
|---|---|
| Subclass H-1B（H-1B Specialty Occupation） | 安保通常不满足专业职业要求，H-1B罕见 |
| Subclass EB-3（EB-3 Skilled/Unskilled Worker） | 极少数情况下，雇主可通过EB-3非技术劳工担保，但门槛高 |
| Subclass Green Card (PERM)（Green Card through PERM） | 雇主需证明无法招到本地工人，难度极大 |

## 9. FAQ 常见问题

**问：What is the average salary for security guards in the US?**
答：According to BLS 2023 data, median annual wage is about $37,920, with top 10% earning over $60,000.

**问：Can security guards immigrate to the US via H-1B or green card?**
答：Highly unlikely. Security guard is not a specialty occupation for H-1B; green card via employment is extremely difficult.

**问：How can security guards advance their career?**
答：With experience, can become patrol supervisor, monitoring center supervisor, or security manager; additional certifications like CPP can lead to corporate security consulting.
