# 生产经理（Production Manager (Manufacturing)）职业分析 · 澳大利亚

**职业代码：133512 – Production Manager (Manufacturing)。**

生产经理负责制造工厂的生产计划、质量、安全与团队，是技术移民职业（需VETASSESS评估），制造与食品/医药领域需求稳定。
