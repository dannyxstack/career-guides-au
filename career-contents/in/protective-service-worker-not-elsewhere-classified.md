# Protective Services Worker Not Elsewhere Classified — career analysis · India

**Occupation code: 5419 (NCO2015)**

This occupation covers protective services workers such as security guards, private investigators, and other security personnel not elsewhere classified. They ensure safety and security of people and property in various settings including commercial, residential, and industrial premises.

**AI replacement risk: medium (★★½☆☆).**

## 7. FAQ

**Q: What is the average starting salary for a security guard in India?**
A: Entry-level security guards typically earn between INR 10,000 and INR 15,000 per month (INR 120,000-180,000 annually). Salaries vary by location, employer, and shift.

**Q: Can a security guard get an Employment Visa to work in India?**
A: Generally no, because the salary threshold for an Employment Visa is around INR 1.8 million (USD 25,000) per year, which is far above typical security guard salaries. Only senior security consultants with high salaries might qualify, but it is very rare.
