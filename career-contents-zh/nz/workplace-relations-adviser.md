# 工作场所关系顾问（Workplace Relations Adviser）职业分析 · 新西兰

**职业代码：223113 (ANZSCO)**

## 6. 移民路径 / PR


| 签证类别 | 说明 |
|---|---|
| Subclass SMC (Skilled Migrant Category Residence Visa) | 通过6分制申请，学历+新西兰本地工作经验可满足分数要求。 |
| Subclass Green List T2 (Green List Tier 2 Work to Residence) | 在该职位工作24个月后可申请居留，需ANZSCO 1-3级且薪资达标。 |
| Subclass AEWV (Accredited Employer Work Visa) | 认证雇主担保，可衔接居留路径，适用于非直接移民情况。 |

## 8. FAQ 常见问题

**问：初级职场关系顾问的薪资范围是多少？**
答：初级顾问年薪约55,000至75,000纽元，取决于雇主规模和地区。

**问：该职业能通过绿色清单移民吗？**
答：可以，该职业在Green List Tier 2（工作转居留）中，需满足薪资和24个月工作经验要求。

**问：是否需要新西兰当地资格认证？**
答：不需要强制注册，但相关学位（如人力资源管理）和英语成绩（雅思7.0）是技术移民的必要条件。
