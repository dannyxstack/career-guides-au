# 居家照护配套协调员（Home Care Package Coordinator）职业分析 · 新西兰

**职业代码：134215 (ANZSCO)**

居家照护配套协调员为长者管理政府补贴的居家照护配套，评估需求、安排服务并管理预算。该职业在新西兰可通过认证雇主工签(AEWV)就业，但不在绿色清单或技术移民职业列表中，移民路径受限。

> **本职业为受限技术移民职业（仅雇主担保 / 偏远地区协议）。** 不在独立技术移民清单（如 189/190）上，可通过雇主担保（482/494）、DAMA 或劳务协议移民，通道受限。

## 6. 移民路径 / PR

## 8. FAQ 常见问题

**问：居家照护配套协调员在新西兰的薪资水平如何？**
答：初级年薪约45,000-55,000纽元，中级55,000-65,000纽元，高级可达75,000纽元。工资可能低于AEWV中位数要求（29.66纽元/小时），但部分雇主可支付更高。

**问：该职业能否通过技术移民新西兰？**
答：不能。居家照护配套协调员不在新西兰技能职业列表或绿色清单中，无法直接申请技术移民。通常只能通过认证雇主工签(AEWV)工作，并需满足工资中位数要求，但初级工资常低于该门槛。

**问：新西兰就业前景如何？**
答：由于人口老龄化，社区护理需求增长，就业机会稳定。但薪资增长有限，晋升至管理岗位可提高收入。需注意，移民政策不友好，职位多由本地居民担任。
