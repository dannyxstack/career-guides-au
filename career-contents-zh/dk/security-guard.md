# 保安（Security Guard）职业分析 · 丹麦

**职业代码：5414 (ISCO08)**

丹麦的保安在购物中心、企业大楼、机场和活动中巡逻和监控场所、控制出入并响应警报。该职业需要警方颁发的保安执照（vagtlicens）。由于安全需求增加，需求稳定。典型雇主是G4S、Securitas和ISS等私营安保公司。

## 5. 未来趋势 / AI替代概率

**发展前景：中（★★½☆☆）**
**AI替代风险：中（★★½☆☆）**

保安工作不易被完全替代，但AI将接管固定岗监控、电子巡逻和基础访客登记等任务，导致入门岗位减少；同时，复杂突发事件处置、人工巡逻判断及客户服务等技能被AI增强，需要提升人机协作能力。

职业发展可以包括进入监督角色、专业安全（如机场、海事），或通过进一步培训成为警察。一些保安转向 IT 安全或风险管理。全职保安通常签订永久合同。兼职和轮班工作很典型。

**最易被 AI 替代的任务：**

- 通过视频分析自动检测入侵、异常行为，代替人工长时间盯监控
- 自动门禁系统（人脸识别/二维码）替代人工核对身份与登记
- 机器人按预设路线电子巡逻，替代部分人工巡视
- 自动生成巡逻日志、事件报告，替代人工记录

**AI 增强的环节：**

- AI辅助分析监控视频，快速回放事件、识别关键帧，提升调查效率
- 智能调度系统根据实时风险优化巡逻路线，增强人工巡逻精准度
- AI语音助手协助处理访客问询，提升服务响应速度与专业性
- 移动终端接收AI预警，指导保安优先处置高风险区域，提高应急能力

**人类护城河：**

- 处理肢体冲突、突发暴力事件等高风险干预需要人类判断与体力
- 对可疑行为的情境理解与灵活沟通（如调解纠纷）
- 人性化安抚、安抚群众情绪等情感交互
- 法律合规与道德判断，如合理使用武力边界

**需构建的技能：**

- 智能安防系统操作与维护（视频分析、门禁、报警平台）
- 基础数据分析与报告解读（如事件统计、风险热力图）
- 人机协作沟通技巧（与AI调度、机器人协同）
- 应急管理与危机干预（冲突化解、急救）
- 数字化转型中的服务意识（访客自助系统引导）
- 持续学习与工具适应能力

**主要增长方向：**

- 活动安保
- 机场安保
- 海上保安
- 企业安全

## 8. FAQ 常见问题

**问：丹麦保安的典型工资是多少？**
答：保安的年薪（税前）约为300,000至350,000丹麦克朗，取决于经验、班次和行业。加班和夜班奖金可增加收入。

**问：非欧盟公民能否在丹麦以保安身份获得工作许可？**
答：通常不能通过正向清单（Positive List），因为该职业不属于短缺职业。薪资限额计划（Pay Limit Scheme）要求薪资高于DKK 465,000，这高于保安的典型薪资。欧盟/欧洲经济区公民可以自由流动。

**问：在丹麦，成为保安需要哪些培训？**
答：你必须完成经批准的保安课程（vagtuddannelse）并从警方获得执照。课程为期约3个月，费用在10,000-20,000丹麦克朗之间。需要无犯罪记录。
