## 三、覆盖面与缺口（务必知悉）

- **规则可直接命中的明确错误**：R1(157)+R2c(20)+R2b(180)+R5(26)+R6(280) ≈ **~660 条**；另 R2a(3,103) 作数值复核筛查、R4(328) 需 LLM 二判。合计规则触达 **< 全量 2%**。
- **规则触达不到的长尾语义错误 ≈ 4,000 条**（mistranslation/omission 的一次性错误）。**这是英文当 11 语种锚点的主要残留风险**，只能靠全量 LLM-judge 定位（成本：本地 gemma 免费但慢/云端 DeepSeek 小钱）。
- **判定**：需你决定是否为高价值字段（faq_a / visa_desc / suitability）加一轮全量 judge，还是接受 2% 残留直接进翻译。

## 四、建议执行顺序（第③步）

1. 跑 R1/R2c/R5/R6 → 收集命中串 → 批量 LLM 重译（带中文锚）→ 回写 `translations`(en)。
2. R2a 3,103 条数值串走 LLM 复核（judge：数值是否与中文一致，不一致才重译）。
3. R4 328 条走 LLM 二判 framing。
4.（可选）高价值字段全量 judge，捞长尾语义错误。
5. 英文清洗定稿后，再以英文为母本翻其余语种。
